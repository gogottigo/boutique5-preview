# BOUTIQUE 5 — fashion concept

Локальный frontend-прототип мужского магазина на Astro, React и Tailwind CSS. Каталог, товары и цены являются демонстрационными.

## Запуск

Требуется Node.js 20.3+.

```sh
npm install
npm run dev
```

Сборка и локальный просмотр production-версии:

```sh
npm run build
npm run preview
```

Доступные страницы: `/`, `/catalog`, `/product/coat` (также `knit`, `shirt`, `jacket`, `trousers`, `shoes`, `overshirt`, `bag`), `/cart`.
